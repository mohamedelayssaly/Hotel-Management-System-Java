
# Hotel Management System

## Project Overview

A desktop-based Hotel Management System developed using Java Swing and MySQL as my final diploma project at CIEL Vocational Training Institute in Tangier, Morocco.

The application integrates four main departments into one centralized management platform, providing separate dashboards and access permissions for each department.

## Main Modules

### 1. Hotel Management
Management of hotel operations.

### 2. Employee Management
Management of employee information and workforce records.

### 3. Stock Management
Management and monitoring of inventory.

### 4. Restaurant Management
Management of restaurant operations.

## User Roles and Access Control

- Department users access their assigned department.
- Each department has its own dedicated dashboard.
- The Manager has full access to all departments.
- Authentication is performed using a username and password.
